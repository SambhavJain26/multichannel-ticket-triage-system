System walkthrough
From request to approved action

One calm workflow, from first message to final handoff.

The automation prepares and explains the next step. It does not replace the manager who authorizes it.

IntakeCapture and match the request

Preserve the exact message, identify the resident and unit, and connect replies to the same open issue.

Request connected
02
TriageInterpret the issue and check safety

Extract trade, symptoms, urgency, and missing information. Fixed rules can only raise priority, never suppress it.

Risk checked
03
ClarifyAsk only for what is missing

Ask one approved follow-up at a time. Save each reply to the same request and run the urgency check again.

Known access and pet details are not asked again.
Context ready

Human checkpointPresent one clear manager decision

Show the original message, urgency reason, property context, approval need, and eligible actions.

Manager control

HandoffSend once, then update the record

A single-use approval prevents duplicate dispatch. Resident status changes only after the approved vendor message succeeds.
