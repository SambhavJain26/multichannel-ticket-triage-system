# Brief icon assets

These ten icon definitions are copied unchanged from the portfolio repository's installed `lucide-react` 0.546.0 package (`dist/esm/icons`). License: ISC, with Feather-derived portions under MIT; see `lucide-license.txt`.

The ReportLab builder parses only each file's `__iconNode` data. It does not execute the JavaScript or require React. `reportlab.graphics.svgpath` renders the original library paths as vectors with a consistent 1.5-unit stroke. Keeping the definitions here makes the PDF builder independent of the portfolio's `node_modules` directory.
